# 🎬 Shakib Animation Library & 3D Generator Studio

প্রফেশনাল ৩ডি মোশন ব্যাজ, লোয়ার থার্ড, অ্যানিমেটেড এলিমেন্ট ও কন্টেন্ট ক্রিয়েশন টুলকিট।

---

## 🚀 সরাসরি ব্রাউজারে ব্যবহার করুন (GitHub Pages)

GitHub রিপোসিটরিতে আপলোড করার পর **Settings > Pages > Deploy from a branch (main / root)** সিলেক্ট করলে সরাসরি লাইভ ব্রাউজার লিঙ্ক পেয়ে যাবেন!

- **ওয়েব এন্ট্রি পয়েন্ট:** `index.html`
- যেকোনো মোবাইল, ট্যাবলেট বা অন্য পিসির ব্রাউজারে ইন্টারনেট থাকলে সরাসরি ওপেন করা যাবে।

---

## 💻 লোকাল পিসিতে চালানোর নিয়ম (Desktop & Browser Modes)

### ১. স্টুডিও লঞ্চার (মেনু নির্বাচন)
- **`start.bat`** ডাবল ক্লিক করুন।
  - `[1]` চাপলে **Electron Desktop App** হিসেবে চালু হবে।
  - `[2]` চাপলে **Local Server + Web Browser** (`http://localhost:4600`) মোডে চালু হবে।
  - `[3]` চাপলে কোনো নোড সার্ভার ছাড়াই সরাসরি ব্রাউজারে চালু হবে।

### ২. সরাসরি ডেস্কটপ মোড (Desktop Standalone)
- **`start-desktop.bat`** ডাবল ক্লিক করুন।

### ৩. সরাসরি ব্রাউজার মোড (Web Browser)
- **`start-browser.bat`** ডাবল ক্লিক করুন।

---

## 🛠️ ডেভেলপার কমান্ড (CLI)

```bash
# ডিপেনডেন্সি ইন্সটল (ঐচ্ছিক)
npm install

# লোকাল সার্ভার রান (Port 4600)
npm start

# ডেস্কটপ অ্যাপ রান (Electron)
npm run desktop
```
